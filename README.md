# Shopping Cart

The task was to create a mocking shopping cart. I have used React, vite, vitest and routes.

App presents the layout page and from there you can visit the pages: home, shop and cart.

The home and the shop use 'loader' - the first to fetch one image and the other to fetch a set of images (the products of the shop). In both cases, I have used https://fakestoreapi.com/ All the orders are stored in localStorage.
